# DESIGN.md — Susilodaya Dhamma School Platform
## Generated by /start on 2026-06-30

This design system is tailored for a Buddhist educational institution, fusing traditional warm tones with clean editorial layout patterns.

## 1. Visual Direction & Style (Non-AI Editorial Aesthetic)
- **Aesthetic:** Clean, grid-based layout utilizing thin 1px dividers to separate sections. Serene and scholarly.
- **Visual Accent:** Mondrian-style blocks using saffron, maroon, and soft gold to create visual framing.
- **Grids:** Asymmetrical column setups on desktop, 1-column on mobile.
- **Custom Shapes:** Lotus petal arched image masks and custom Bodhi-leaf shape contours for card headers.
- **Backgrounds:** Moonstone (sandakada pahana) watermark patterns in low-contrast on public page backgrounds.
- **Portal Unified Colors:** All portal dashboards (Admin, Teacher, and Student) share the warm cream (#FFF8F0) background, light sand (#F0E6D6) surfaces, and charcoal text.

## 2. Animation Guidelines & Scroll Triggers

### A. Global Elements
*   **Header Nav & Menu:** Elements fade-in (`opacity: 0 -> 1`) and slide down (`translateY(-20px) -> 0`) on initial load (duration: 450ms). Back-drop blur filter transitions when navigation becomes sticky on scroll.
*   **CTA Buttons:** Gentle scale lift (`scale: 1 -> 1.05`) and background tint deepening on hover with `transition-duration: 200ms`.

### B. Element-Specific Animation Mappings (Scroll Triggers)
*   **Hero Playfair Main Title:** Text reveal scroll animation. Words or lines are split and slide up (`translateY(100%) -> 0`) through a mask as they enter the viewport.
*   **Hero Lotus Arched Photo:** Fades in and slides up (`translateY(30px) -> 0`) simultaneously, accompanied by a slow zoom on hover (`scale: 1 -> 1.04`).
*   **About Us Timeline:** Parallax slide-in. Timeline text nodes on the left slide in from the left, and nodes on the right slide in from the right. The connector line draws down using an SVG path animation (`stroke-dashoffset` driven by scroll position).
*   **Gallery collage:** Staggered drift. Images drift vertically at varying scroll speeds (parallax factor of 0.05 for back items, 0.1 for front items), with a clean shadow scale-up on mouse hover.
*   **Enrollment journey:** Page slide wipes. The steps wipe horizontally when transitioning (`translateX(-100% -> 0)`), and the stepper's golden thread draws itself forward.
*   **Student Progress Path:** A vertical timeline that grows node-by-node. When the timeline is revealed, the circles bounce in, and the connectors draw downwards in sequence.

## 3. UI Component Specs
- **Buttons:** Main CTA buttons are saffron (#E8A317) with white text, using `rounded-md` and slight scale lift on hover.
- **Navigation:** Fixed navigation with inline desktop menu and accordion-style mobile drawer.
- **Inputs:** Light Sand (#F0E6D6) background with solid border that transitions to Saffron on focus.
- **Datagrid:** Inter font, clean row lines, hover highlight on table rows.
- **Custom Canvas Map:** A custom HTML5 Canvas rendering component styled with saffron, maroon, and gold colors, rendering the school location and surrounding area with custom icons and smooth panning.
